title: See solar PV installation requests
tags: pv, solar, installs, enquiries, requests, form
page: admin/pv-installs
---

**PV Installs** lists the solar PV installation requests saved by your site's enquiry form. It appears as a **PV Installs** item at the top of the admin menu.

If the page says the site has no PV installation requests table, there is nothing to list yet, and it is not a fault.
